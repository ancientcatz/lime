# Install

1. Install an Xposed framework that supports libxposed API 102 (NPatch or LSPosed).
2. Download the latest release APK from [releases](https://github.com/ancientcatz/lime/releases).
3. Install the APK on your device.
4. Open NPatch (or LSPosed) and enable the Lime module.
5. Select the target apps in the module's scope.
6. Reboot or force-stop the target app for the hook to take effect.

To change an app's orientation, open Lime, tap the app, and pick an orientation from the dialog.
