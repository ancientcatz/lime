# Build

## Prerequisites

- JDK 21
- Android SDK with `platforms;android-37.0` and `build-tools;37.0.0`

## Steps

```sh
./gradlew --warning-mode=all clean
./gradlew --warning-mode=all assembleDebug
./gradlew --warning-mode=all assembleRelease
```

The debug APK is signed with the Android debug key. The release APK is unsigned unless
the `LIME_KEYSTORE_FILE`, `LIME_KEYSTORE_PASSWORD`, `LIME_KEY_ALIAS`, and `LIME_KEY_PASSWORD`
environment variables are set.

## CI

Two GitHub Actions workflows live in `.github/workflows/`:

- `ci.yml` — runs on push and pull requests. Lints, runs unit tests, and builds both debug
  and release APKs. Uploads them as workflow artifacts. Does not create a release.
- `release.yml` — creates a draft GitHub Release. Triggered by pushing a tag (`v*`) or
  manually via workflow_dispatch. Accepts a `tag` input (release tag) and a `debug` input
  (include the debug APK).

Release notes are generated by [git-cliff](https://github.com/orhun/git-cliff) from the
commit history since the previous tag.
